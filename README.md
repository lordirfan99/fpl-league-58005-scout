## Important limitation

This is a **pre-GW1** snapshot. Current standings, picks, captaincy and transfer behaviour were unavailable. Re-run the collector after deadlines and blend live evidence into the preseason prior.

## Weekly Pipeline

After **every gameweek finishes**, the pipeline runs automatically (cron: every Friday 20:00 UTC) to:

1. **Fetch** — Pull GW data for all league members: picks, points, transfers, chips, captain choices
2. **Analyze** — Generate comprehensive reports:
   - **Main Report** — League-wide stats: ownership, formations, transfers, captain trends, differentials
   - **Elite Watch** — Detailed breakdown of top ELITE/SHARP managers' exact squads, captains, transfers
   - **Strategy** — Tactical insights: vulnerabilities, template weaknesses, differential opportunities
3. **Commit** — Push to GitHub for historical tracking

### Historical Data

Each GW's data is preserved in the repo:
- `data/gw1_data.json` → All GW1 picks, transfers, chip usage
- `reports/GW1/` → Full analysis reports for GW1
- Same structure for GW2, GW3, ... GW38

This allows tracking how each manager's team evolves across the season.
