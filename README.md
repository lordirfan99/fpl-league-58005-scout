## 📋 What This Repo Does

This repo tracks **FPL League 58005 (LIGA FPL KK OLD BOYS)** and **League 131997 (OVERALL IFE)** — 2,232 unique managers across both leagues.

Every gameweek after the deadline, the **GW pipeline** runs automatically to:
1. **Fetch** — Pull every manager's GW data: points, squad picks, captain, transfers, chips used
2. **Analyze** — Generate ownership stats, captaincy trends, formation analysis, elite watch
3. **Dashboard** — A live web dashboard at **fpl-scout-intelligence.netlify.app** shows everything in real-time

## 🚀 Quick Start

### View the Dashboard
Just open **https://fpl-scout-intelligence.netlify.app** in any browser (desktop or mobile).

```bash

# 2. Serve the dashboard
```

```bash

# Generate analysis reports
python scripts/generate_analysis.py --gw 1

python scripts/run_gw_pipeline.py
```

|:-----|:--------------|
| **Overview** | KPIs (manager count, avg GW points, top score, rank risers), top 10 performers, captaincy bar chart, points distribution histogram, template XI (most owned players), rank movers |

## 🚢 Deployment

### Netlify (current)
The dashboard is deployed at **https://fpl-scout-intelligence.netlify.app**.
Deploy method: manual zip upload via Netlify API.

To re-deploy after changes to `dashboard/`:
```bash
# Push to GitHub (auto-triggers nothing — manual deploy needed)
git push origin master

# Then deploy via Netlify API (requires NETLIFY_AUTH_TOKEN)
# The deploy script zips dashboard/ + data/ and uploads
```

Files needed in deploy:
- `dashboard/index.html` — Main page
- `dashboard/app.js` — App logic
- `dashboard/styles.css` — Styling (desktop + mobile)
- `data/gw1_league*.json` — GW data files

- `_headers` — Force `Content-Type: application/json` for `/data/*`

## 🔄 Weekly Pipeline

The pipeline runs automatically every **Friday 20:00 UTC** (after GW deadline):

1. **`fetch_gw_data.py --gw N`** — Fetches all managers' picks, transfers, chips

3. **`git commit + push`** — Commits data + reports to GitHub

## 🛠 Troubleshooting

### Dashboard shows blank / data not loading
1. Open browser DevTools (F12) → Console tab
2. Look for red error messages
3. Most common: `Unexpected token '<'` — means `_redirects` is catching data paths
   - **Fix:** Ensure `_redirects` only has `/ /index.html 200`, NOT `/* /index.html 200`
4. Check network tab: `/data/gw1_league58005_compact.json` should return `200` with `Content-Type: application/json`

### Data files return 0 bytes
- Clear browser cache (hard refresh: Ctrl+Shift+R)
- Check Netlify deploy log for errors

### "Dataset unavailable" error
- The full data JSON (`gw{N}_league{L}_data.json`) might not be deployed
- Deploy the full data files alongside the dashboard
